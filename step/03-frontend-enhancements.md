# 步骤 3：前端功能增强

## 完成时间

2026-04-18

## 做了什么

在第二步前端页面基础上，添加了 9 个实用功能（截止日期 C 暂未加入，需改数据库表结构）。

## 新增功能

| 功能 | 说明 |
|------|------|
| A. 任务可编辑 | 点击"编辑"按钮直接在列表中修改内容和截止日期，支持回车保存 / Esc 取消 |
| B. 任务搜索 | 工具栏输入关键词，实时过滤任务列表 |
| C. 任务截止日期 | 添加/编辑任务时可设置截止日期，逾期显示红色标记 |
| E. 任务计数统计 | 左下角显示"已完成 X / 共 Y" |
| F. Toast 提示 | 操作成功/失败在右上角弹出提示，替代 alert |
| G. 添加任务动画 | 新任务从上方滑入（taskEnter 动画） |
| H. 快捷键 | 在任务输入框按回车直接添加任务 |
| I. 任务草稿本地保存 | 输入内容后刷新页面，内容不丢失（localStorage） |
| J. 批量操作 | 每条任务左侧可选中，支持全选、批量删除、批量完成 |

## 注意事项

1. **Toast 提示** - 右上角弹出，2.5s 后自动消失，错误提示停留 3.5s
2. **草稿保存** - 输入框失焦时保存，提交成功或页面跳转时清除
3. **批量选择** - 切换标签页或搜索后，之前选中的 ID 保留，但只对可见任务操作
4. **编辑模式** - 编辑 input 支持回车保存、Esc 取消，切换标签页自动退出编辑
