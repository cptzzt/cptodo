# 数据库表结构

> **本文件作用：** 记录 todo_app 数据库中所有表的字段、类型和说明，包括已废弃的表。每次执行数据库迁移后必须同步更新此文件。新对话接手开发时，先看这个文件了解当前数据结构。

> 数据库名：`todo_app`，每次结构变更都要更新此文件。

---

## users — 用户表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK | 自增主键 |
| username | VARCHAR(50) NULL | 用户名（可为空，未设置时只能用邮箱登录） |
| password | VARCHAR(255) | bcrypt 加密后的密码 |
| email | VARCHAR(255) UNIQUE NULL | 邮箱地址（可用于登录） |
| no_child_delete_prompt | TINYINT(1) | 不再提示"有子项的项目禁止删除"（0=提示，1=不提示） |
| theme_preference | VARCHAR(20) | 主题偏好（forest-sage, warm-linen, lavender-mist, minimal-ink） |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

---

## projects — 项目表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK | 自增主键 |
| user_id | INT FK→users.id | 所属用户 |
| name | VARCHAR(100) | 项目名称 |
| sort_order | INT | 排序（数字越小越靠前） |
| is_private | TINYINT(1) | 是否隐私（0=正常，1=隐私） |
| deleted_at | TIMESTAMP NULL | 软删除时间，NULL=正常，有值=在回收站 |
| created_at | TIMESTAMP | 创建时间 |

---

## items — 任务/随笔/重复任务（统一存储）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK | 自增主键 |
| user_id | INT FK→users.id | 所属用户 |
| project_id | INT FK→projects.id NULL | 所属项目，NULL=随笔或重复任务 |
| project_label_id | INT FK→project_labels.id NULL | 项目专属标签，0 或 1 个，用于项目内分类 |
| parent_id | INT FK→items.id NULL | 父节点（历史遗留，当前未使用层级嵌套） |
| type | ENUM('note','folder','task') | note=随笔，folder=目录（当前未使用），task=任务 |
| title | VARCHAR(255) | 标题 |
| content | TEXT NULL | 内容（仅 task） |
| notes | TEXT NULL | 备注 |
| due_date | DATE NULL | 截止日期 |
| completed | TINYINT(1) DEFAULT 0 | 是否完成 |
| priority | ENUM('normal','important') | 优先级 |
| recurring | ENUM('daily','weekly','monthly') NULL | 重复周期，NULL=不重复，有值=重复任务 |
| recurring_target | INT DEFAULT 1 | 频次目标，1=固定日期（原行为），>1=每周N次 |
| recurring_count | INT DEFAULT 0 | 本周已完成次数（仅 target>1 时使用） |
| is_private | TINYINT(1) | 是否隐私（0=正常，1=隐私） |
| shelved | TINYINT(1) DEFAULT 0 | 是否搁置（0=正常，1=暂时从视野中隐藏） |
| show_early | TINYINT(1) DEFAULT 0 | 提前显示（0=仅截止日显示，1=截止前每天显示在今天视图） |
| sort_order | INT DEFAULT 0 | 排序 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 最后更新时间（自动更新） |
| updated_at | TIMESTAMP | 更新时间 |
| deleted_at | TIMESTAMP NULL | 软删除时间，NULL=正常，有值=在回收站 |

### items 的三种用途

| 用途 | type | project_id | recurring | 说明 |
|------|------|------------|-----------|------|
| 随笔 | note | NULL | NULL | 不属于任何项目，左侧随笔视图 |
| 普通任务 | task | 有值 | NULL | 属于某个项目 |
| 重复任务（固定日期） | task | NULL | daily/weekly | recurring_target=1，每周选固定周几，周期结束时自动重建 |
| 重复任务（频次目标） | task | NULL | weekly | recurring_target>1，如"每周运动3次"，只展示在"本周"视图，周期结束重置计数 |

## tags — 标签表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK | 自增主键 |
| user_id | INT FK→users.id | 所属用户 |
| name | VARCHAR(50) | 标签名称（同一用户唯一） |
| color | VARCHAR(7) | 标签颜色（十六进制，如 #4f46e5） |
| is_private | TINYINT(1) | 是否隐私（0=正常，1=隐私） |
| created_at | TIMESTAMP | 创建时间 |

---

## item_tags — 任务与标签的关联表

| 字段 | 类型 | 说明 |
|------|------|------|
| item_id | INT FK→items.id | 条目 ID |
| tag_id | INT FK→tags.id | 标签 ID |

联合主键 (item_id, tag_id)，双方 CASCADE 删除。

---

## project_labels — 项目专属标签表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK | 自增主键 |
| project_id | INT FK→projects.id | 所属项目（CASCADE 删除） |
| user_id | INT FK→users.id | 所属用户（CASCADE 删除） |
| name | VARCHAR(50) | 标签名称（同一项目内唯一） |
| color | VARCHAR(7) DEFAULT '#4f46e5' | 标签颜色（十六进制） |
| created_at | TIMESTAMP | 创建时间 |

与全局标签（tags）的区别：项目专属标签只在对应项目内使用，任务只能绑定 0 或 1 个项目专属标签；全局标签可跨项目关联，任务可绑定多个。

---

## verification_codes — 邮箱验证码表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK | 自增主键 |
| email | VARCHAR(255) NOT NULL | 邮箱地址 |
| code | VARCHAR(6) NOT NULL | 6位验证码 |
| type | ENUM('login','register') | 类型：login=登录，register=注册 |
| used | TINYINT(1) DEFAULT 0 | 是否已使用（0=未使用，1=已使用） |
| expires_at | TIMESTAMP NOT NULL | 过期时间 |
| created_at | TIMESTAMP | 创建时间 |
